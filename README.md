# Turn-Based RPG — Unity

A personal turn-based RPG project developed in **Unity**, inspired by *Dragon Quest Monster: Joker*.

This project is a personal RPG project combining strategic 3v3 monster battles, abilities, and a monster fusion system within an original fantasy universe built around the concept of pacts.
Developed as part of my journey into Game Programming, the project focuses on gameplay systems, combat mechanics, UI programming, and interactive combat presentation.


## Features

- **3v3 Turn-Based Combat** — A battle system featuring multiple playable monsters and enemy teams.
- **Combat Actions** — Basic attacks, abilities, guarding, and item interactions.
- **Target Selection** — Interactive enemy targeting during combat.
- **Monster Fusion** — A system allowing two monsters to fuse into a new creature, with inherited abilities.
- **Controller Support** — Keyboard and gamepad support with dynamically adapting UI prompts.
- **Combat Presentation** — Camera transitions, animations, and visual effects for combat actions.

## Technical Information

- **Engine:** Unity 6 (URP)
- **Language:** C#
- **Platform:** PC
- **Development:** Solo project
- **Status:** Work in progress
